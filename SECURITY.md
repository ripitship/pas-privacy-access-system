# Sensitive findings / Sensible Befunde

Do not post vulnerabilities, exploit proofs, secrets, private state, personal data or customer details in public issues. This locally prepared showcase has no active reporting service. Before launch, the operator must configure and verify private vulnerability reporting where available, or explicitly grant a private review channel. When such a route is available, use it for a minimal confidential report. If no approved private route exists, do not place sensitive material in the public channel; wait for an approved route. No response time or bounty is promised. This documentation tree is not a production-supported software release.

Keine Schwachstellen, Exploit-Nachweise, Geheimnisse, privaten Zustände, personenbezogenen Daten oder Kundendetails in öffentliche Issues stellen. Diese lokal vorbereitete Präsentation hat keinen aktiven Meldedienst. Vor Start muss der Betreiber, soweit verfügbar, private Schwachstellenmeldung einrichten und prüfen oder ausdrücklich einen privaten Review-Kanal gewähren. Sobald ein solcher Weg besteht, dort einen minimalen vertraulichen Bericht einreichen. Ohne freigegebenen privaten Weg keine sensiblen Inhalte öffentlich einstellen; auf einen freigegebenen Weg warten. Keine Reaktionszeit oder Prämie wird zugesagt. Dieser Dokumentationsbaum ist keine produktionsunterstützte Softwareveröffentlichung.
