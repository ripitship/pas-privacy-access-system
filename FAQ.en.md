## FAQ

Is PAS free open source? No. The source remains private under the existing proprietary software restrictions. Free technical evaluation is intended only under agreed terms. Permanent business use needs agreement.

Does no mandatory email mean anonymous or legally cleared? No. Operators must assess identity, privacy and legal obligations in context. No complete anonymity or compliance certification is claimed.

Can I message the initiator privately on GitHub? No general GitHub private-message feature is assumed. Ordinary requests can use public issues only after setup. Sensitive findings require a configured private reporting or explicitly granted review channel.

Does asking for code grant access? No. Individual approval, terms, hosting choice and minimum necessary access precede disclosure. There is no response SLA.

Can I run this documentation repository? It contains documentation and a Python standard-library documentation checker, not PAS software or an executable demo.

## Roadmap

Near-term goals: qualified consultant feedback, focused private integration reviews, explicit operator evidence and threat-model assessment. Production gates include independent security/SCA review, rights/contact assessment, actual browser/authenticator coverage, isolated key/witness custody, restore/HA and deployment evidence. P2 stays blocked. These are goals without delivery dates or commercial commitments.
