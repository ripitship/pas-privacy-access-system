# Contributing / Beiträge

Non-confidential questions and documentation feedback are welcome through issues after setup. Check the [rights notice](NOTICE.md), [review process](REVIEW.md) and [security policy](SECURITY.md). Propose a documentation scope before submitting content; do not submit PAS source, runtime artifacts, customer data, secrets or material without cleared contribution rights. No software contribution license or rights transfer is implied. Changes must preserve equivalent English/German facts. After manual review, refresh hashes with `python3 tools/check_public.py . --repository --refresh-inventory`; validate with `python3 tools/check_public.py . --repository`. Repository mode permits only the root Git metadata directory; exported trees use strict mode without this flag. CI validates documentation only. A maintainer reviews all changes manually; automation does not publish.

Nicht vertrauliche Fragen und Dokumentationsfeedback sind nach Einrichtung über Issues willkommen. [Rechtehinweis](NOTICE.md), [Review-Prozess](REVIEW.md) und [Sicherheitsrichtlinie](SECURITY.md) beachten. Dokumentationsumfang vor Einreichung abstimmen; keinen PAS-Code, Laufzeitartefakte, Kundendaten, Geheimnisse oder Inhalte ohne geklärte Beitragsrechte einreichen. Keine Software-Beitragslizenz oder Rechteübertragung ist impliziert. Änderungen müssen semantisch gleiche englische/deutsche Fakten erhalten. Nach manueller Prüfung Hashes mit `python3 tools/check_public.py . --repository --refresh-inventory` aktualisieren; mit `python3 tools/check_public.py . --repository` prüfen. Repository-Modus erlaubt ausschließlich das Git-Metadatenverzeichnis im Stamm; Exporte nutzen strikten Modus ohne diesen Schalter. CI prüft nur Dokumentation. Ein Verantwortlicher prüft alle Änderungen manuell; Automatisierung veröffentlicht nichts.
